# Security Tools I Have Used

| Tool | What I use it for |
| --- | --- |
| Nmap | Network discovery and service enumeration |
| Wireshark | Packet analysis |
| tcpdump | Command-line packet capture |
| curl | HTTP requests and web inspection |
| Gobuster | Web content discovery |
| Burp Suite | Inspecting web requests in labs |
| John the Ripper | Password and hash concepts in labs |
| SQLMap | SQL injection testing concepts |
| Metasploit | Exploitation framework fundamentals |
| Git / GitHub | Version control and documentation |
| VMware | Isolated lab environments |

My goal is to understand what each tool is doing rather than letting the tool make every decision for me.
