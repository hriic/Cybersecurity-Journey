# Simple CTF — Lessons Learned

This was one of the early labs where I started combining individual skills into a process.

## What I practiced

- Starting with service discovery
- Checking service versions
- Expanding enumeration instead of assuming the first scan found everything
- Web content discovery
- Looking for application and version clues
- Researching findings
- Working with remote access later in the lab

## What changed in my thinking

Earlier, it was easy to see tools as separate commands. This lab made the workflow clearer: one result should create the question for the next step.

Finding a web server does not mean I immediately need an exploit. First I need to understand the application, directories, technologies, authentication and anything unusual.

## Main takeaway

**Enumeration before assumptions.**

Needing documentation, search or help during a lab is normal while learning. What matters is going back afterward and understanding why the solution worked.
