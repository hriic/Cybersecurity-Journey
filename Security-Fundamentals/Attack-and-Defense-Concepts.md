# Attack and Defense Concepts

## Topics I have covered

- Phishing
- SMS phishing
- Malvertising
- Zero-day vulnerabilities
- Multi-factor authentication
- Web shells
- Least privilege
- Application allowlisting
- Web Application Firewalls
- Command and Control
- Exfiltration
- Ransomware
- DoS and DDoS

I learned the basic distinction between denial-of-service and distributed denial-of-service attacks, why least privilege reduces impact, and why encrypted traffic can still require monitoring.

Studying both offensive and defensive concepts helps me understand not only how a technique works, but also what defenders might observe.
