# Security Testing Frameworks

## Cyber Kill Chain

1. Reconnaissance
2. Weaponization
3. Delivery
4. Exploitation
5. Installation
6. Command and Control

## MITRE ATT&CK

I have practiced the idea of mapping findings and observed behavior to ATT&CK technique identifiers.

## PTES

PTES helped me understand that penetration testing includes planning, scope, rules of engagement, technical work and reporting. The technical part is only one part of an engagement.

## NIST SP 800-115

I studied it as a technical security testing and assessment guide.

## OSSTMM

I have covered its structured testing approach and RAV-related material.

## OWASP WSTG

I have studied parts of the Web Security Testing Guide and its structured testing categories.

The main lesson is that methodology matters. A good assessment should be structured, repeatable and documented.
