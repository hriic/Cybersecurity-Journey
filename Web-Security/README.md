# Web Security

These are notes from my web-security study and authorized labs.

## Enumeration

I start by checking the web server, page title, headers, robots.txt, visible technologies, directories, login pages and supported HTTP methods.

## Tools I have practiced

I use `curl` to inspect requests and responses from the terminal, Gobuster for content discovery, and Burp Suite to understand and inspect HTTP traffic.

I have also studied SQL injection concepts and SQLMap in training environments, along with WebDAV and the security impact of unsafe configurations.

The main thing I am working on is understanding what the application is doing before reaching for automated tools.
