# WebDAV and SQLMap

## WebDAV

I encountered WebDAV during a legal lab. I learned to recognize the service, inspect HTTP methods and understand authentication responses.

The bigger lesson was that an HTTP service can expose more functionality than a normal web page, so service-specific enumeration matters.

## SQLMap

I have studied SQLMap as an automation tool for SQL injection testing in authorized environments. I want to understand the underlying request, input point and database behavior instead of treating automation as a magic command.
