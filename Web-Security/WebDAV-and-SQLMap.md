## WebDAV lesson

WebDAV extends HTTP with remote resource-management methods. The important security question is not simply whether WebDAV exists, but how authentication, authorization, write permissions, file handling, and execution permissions interact.

## SQLMap lesson

SQLMap is an automation tool for authorized SQL injection testing. I use it only after understanding the suspected input, the exact request, session requirements, and the evidence supporting the SQL injection hypothesis.

The detailed notes above preserve the underlying methodology instead of treating either technology as a one-command technique.
