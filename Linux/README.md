## What I have learned

Linux permissions control who can read, write, or execute files. I also use commands such as `ps aux` and `ss -tulpn` to understand running processes and listening services.

The kernel is the core of the operating system. I use `uname -r` to check the running kernel release.

My goal is to become comfortable enough with the terminal that I do not depend on GUI tools.
