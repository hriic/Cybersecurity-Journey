# Virtual Lab

I use VMware to build isolated environments for cybersecurity practice.

## Systems I have worked with

- Kali Linux
- Parrot Security
- Windows 10
- Windows 7
- Windows Server
- Metasploitable 2

## Networking

I have worked with NAT and host-only networking while troubleshooting lab connectivity.

Using virtual machines lets me practice administration, networking and security concepts without mixing the lab environment with my main system.
