# SentinelX

SentinelX is a SOC-style project I built while learning defensive security and software development.

## Stack

- FastAPI backend
- SQLite
- Vue / Vite frontend
- Linux log collection

## Security features and concepts

- Alerts
- Events
- Incidents
- Users
- Reports
- Observables
- Detection rules
- MITRE ATT&CK mapping
- Dashboarding
- Syslog, SSH and firewall parsing

Building it helped me think about how events are collected, parsed, displayed and turned into useful information for an analyst. It also connected backend development, frontend development, APIs, logs and security concepts in one project.
