# TryHackMe — Hands-on Learning

TryHackMe is one of my main environments for legal hands-on practice. I use it to turn concepts into repeatable technical skills rather than treating completed rooms as collectibles.

## Systems foundation

I have worked through Windows Fundamentals, Linux Fundamentals, Windows PowerShell, Linux shells/CLI and Active Directory basics. These topics give me context for what I see during enumeration instead of making every service look unfamiliar.

## Networking and protocols

I have practiced HTTP, DNS, Telnet, FTP, SMTP, POP3 and IMAP. Manually interacting with older protocols helped me understand banners, commands, request/response behavior and the security difference between plaintext and encrypted communication.

## Nmap

My Nmap practice covers host discovery, TCP scanning, service/version detection, default NSE scripts, script discovery, scan reasoning and output formats. I am moving from "run Nmap" toward using each scan to answer a specific enumeration question.

## Offensive-security foundations

I have covered passive vs active reconnaissance, exploitation basics, offensive-security tooling, the Cyber Kill Chain and several testing frameworks. The most important lesson has been that exploitation is only one phase of a larger assessment.

## Web hacking

I have practiced source inspection, technology fingerprinting, content discovery, HTTP methods, curl, Gobuster, Burp Suite fundamentals, WebDAV concepts and SQLMap/SQL-injection concepts in training labs.

## CTF practice

Beginner CTFs are where I test whether I can connect the pieces without being given the exact next command. My process is usually:
**scan → enumerate → investigate evidence → obtain authorized access → enumerate locally → privilege escalation → document lessons**.

When I use a walkthrough or external hint, I try to understand the missing idea and then add it to my own methodology instead of copying the answer.

## Current focus

I am working through junior penetration-testing material and deliberately trying to become more independent. The metric I care about is not only whether I completed a room, but whether I can explain the protocol, command, output and reasoning afterward.
